# Sample media

Put a sample traffic clip here, e.g. `sample_traffic.mp4`, and reference it from
this README so reviewers know what to play.

You can generate a synthetic one (clearly watermarked as demo data):

```bash
cd CTAS
python scripts/make_sample_video.py --seconds 20
```

A ready-made `sample_traffic.mp4` is generated during the build verification
step and included in the packaged ZIP when available.
